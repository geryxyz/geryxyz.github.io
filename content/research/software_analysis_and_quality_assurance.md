I use static and dynamic software analysis to understand software behavior, assess test quality, and support fault localization. Topics include code coverage, mutation testing, test-to-code traceability, unit-test organization, and context-aware debugging. The [iFL4Eclipse](https://github.com/sed-szeged/iFL4Eclipse) prototype brings interactive fault localization into the Eclipse IDE.
