Software engineering decisions depend on more than the current state of source code. Historical changes, developer activity, and domain knowledge can provide complementary evidence about the effort required to maintain a system and the significance of analysis results.

Our work on [[research/bibliography/prediction_of_software_development_modification_effort_enhanced_by_a_genetic_algorithm|modification-effort prediction]] combined product and process metrics with machine learning, using a genetic algorithm to calibrate model parameters. Rather than estimating effort solely from code properties, this approach incorporates information about how the software evolves. A complementary perspective emerged in [[research/bibliography/identifying_wasted_effort_in_the_field_via_developer_interaction_data|our field study of wasted development effort]], which used seven months of IDE interaction data to construct micro-productivity profiles across project milestones and application layers. These approaches connect cost estimation with the study of developer behavior in [[research/human_centered_software_engineering|human-centered software engineering]].

Measurements alone do not necessarily capture the meaning of a system. Our work on [[research/bibliography/capturing_expert_knowledge_to_guide_data_flow_and_structure_analysis_of_large_corporate_databases|capturing expert knowledge for corporate database analysis]] addresses the role of human expertise in interpreting data flow and structure. Similarly, [[research/bibliography/towards_project_aware_actionability_detection_for_coding_rule_violations|project-aware actionability detection]] applies active learning to distinguish useful coding-rule warnings from diagnostic noise, connecting data-driven analysis with [[research/software_security_and_ai_assisted_engineering|software security and AI-assisted engineering]].

Beyond these software-specific applications, [[research/bibliography/predictive_complex_event_processing_a_conceptual_framework_for_combining_complex_event_processing_and_predictive_analytics|our conceptual framework for predictive complex event processing]] explores combining event detection with predictive analytics so that responses can be proactive rather than purely reactive. A collaborative chapter on [[research/bibliography/application_of_generative_ai_in_resource_optimization_in_healthcare_systems|generative AI for resource optimization in healthcare]] addresses another application domain for data-driven decision support.

The relationship between software measurements, effort estimation, visualization, and test quality is also a central theme of [[research/bibliography/utilizing_static_and_dynamic_software_analysis_to_aid_cost_estimation_software_visualization_and_test_quality_management_statikus_s_dinamikus_forr_sk_d_elemz_s_felhaszn_l_sa_k_lts_gbecsl_s_szoftver_vizualiz_ci_s_teszt_min_s_g_menedzsment_sor_n_|my doctoral dissertation]].
